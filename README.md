# Лабораторная работа №1: дерево сертификатов

Автоматическое создание трёхуровневой цепочки сертификатов X.509 с помощью OpenSSL:

```text
Корневой УЦ ВШЭ → УЦ учебной группы → сертификат студента
```

Проект основан на скрипте и конфигурации преподавателя. Subject пользовательского сертификата персонализирован. В сертификаты добавлены `subjectKeyIdentifier` и `authorityKeyIdentifier`, в сертификат группы — `nameConstraints`, разрешающее почтовые имена домена `edu.hse.ru`.

## Файлы

- `do_it.bat` — создание ключей и сертификатов, сборка контейнера PKCS#12 и импорт в Windows.
- `openssl.cnf` — конфигурация OpenSSL и расширения сертификатов.
- `.gitignore` — исключение закрытых ключей и промежуточных файлов из Git.

## Требования и запуск

Windows, OpenSSL и права администратора для импорта в хранилища компьютера. В скрипте указан установленный OpenSSL из `C:\Program Files\Git\usr\bin`; на другом компьютере путь необходимо скорректировать.

В PowerShell, запущенном от имени администратора:

```powershell
cd C:\Dima\PKI\Lab_01
.\do_it.bat
```

Скрипт работает без ручного ввода, останавливается при ошибке и перезаписывает одноимённые выходные файлы при повторном запуске. Корневой сертификат добавляется в доверенные корни компьютера, промежуточный — в хранилище промежуточных УЦ, пользовательский — в личное хранилище компьютера.

## Результаты

- `rootca.crt`, `groupmca.crt`, `usercert.crt` — три сертификата цепочки.
- `*.key` — зашифрованные закрытые ключи RSA 4096 бит.
- `*.csr`, `*.srl` — запросы и файлы серийных номеров.
- `certs.crt`, `final.p12` — объединённая цепочка и контейнер с пользовательским ключом для импорта, предусмотренные исходным шаблоном.
